# scully_mba (fork) + ox_lib
A resource to change the interior of gabz mba and sync it across all players including newly connected ones.

This is a fork of [scully_mba](https://github.com/Scullyy/scully_mba) all credits to him, simply forked to add ox_lib support for easy menu to select options for user convenience.
